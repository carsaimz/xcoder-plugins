# Diff Tool

Compare two texts or the selection against the clipboard with a real LCS line diff.

**Diff Tool** computes a line-by-line longest-common-subsequence diff entirely offline. Paste both texts (or start from the current selection), see `+ / −` lines, view with context, or copy a patch-style diff. The second command diffs the editor against the clipboard — perfect to check what changed between two versions of a file.

## Português
**Diff Tool**: diff linha a linha (LCS) entre dois textos ou entre a seleção e a área de transferência — mostra `+ / −`, contexto completo e cópia em estilo patch. Atalho `Ctrl-Alt-9`.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
