# Timestamp Tools

Convert epoch ⇄ ISO ⇄ human dates and insert the current timestamp.

**Timestamp Tools** offers two commands: *Insert timestamp* (epoch seconds, epoch ms, ISO 8601 or localized date at the cursor) and *Convert* (accepts `1737936000`, `1737936000000` or any ISO string and shows ISO, local, relative time and both epochs).

## Português
**Ferramentas de timestamp**: insere o instante atual (epoch s/ms, ISO, local) e converte entre epoch, ISO e datas humanas com tempo relativo.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
