# Base Converter

Convert integers between decimal, hex, binary, octal and base36.

**Base Converter** accepts `42`, `0x2A`, `0b101010` and `0o52` inputs (prompt or selection) and shows all representations at once, including negative values.

## Português
**Conversor de bases**: converte inteiros entre decimal, hex, binário, octal e base36 — aceita entrada nos formatos `42`, `0x2A`, `0b101010`, `0o52`. Atalho `Ctrl-Alt-2`.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
