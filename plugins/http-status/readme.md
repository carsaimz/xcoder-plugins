# HTTP Status

Browse, lookup and insert HTTP status codes.

**HTTP Status** lists the common 1xx–5xx codes with their official names, looks up the code under the cursor/selection and inserts a chosen code at the cursor — handy when writing handlers, docs or tests.

## Português
**HTTP Status**: consulta os códigos 1xx–5xx com os nomes oficiais, procura o código sob o cursor e insere no editor.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
