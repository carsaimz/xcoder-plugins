# Query String Tools

Parse and build URL query strings as JSON.

**Query String Tools** converts `?a=1&b=2` into pretty JSON and back, decoding `+` and percent-escapes. Works on the selection or the whole document; a show-only mode parses without touching the editor.

## Português
**Query string ⇄ JSON**: converte parâmetros de URL em JSON (e volta), decodificando `+` e escapes percentuais.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
