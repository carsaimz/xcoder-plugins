# Password Generator

Generate cryptographically random passwords directly into the editor.

**Password Generator** uses the Web Crypto API (`crypto.getRandomValues`) — no pseudo-random Math.random. Choose length and character sets (lowercase, uppercase, digits, symbols); the generator guarantees at least one character of every selected set and inserts the result at the cursor. A quick command copies a 20-char password straight to the clipboard.

## Português
**Gerador de passwords**: passwords aleatórias criptográficas (Web Crypto) — comprimento e conjuntos configuráveis, garantindo um carácter de cada conjunto. Inserção no cursor ou cópia rápida de 20 caracteres. Atalho `Ctrl-Alt-3`.
