# CSV ⇄ JSON

Convert CSV to JSON and back, with proper RFC4180 quoting.

**CSV ⇄ JSON** parses quoted fields, escaped quotes, commas inside quotes and `;` delimited files. JSON arrays of objects are serialized back to CSV with automatic column union and escaping. Works on the selection, the document or pasted input (result to the clipboard).

## Português
**CSV ⇄ JSON**: converte tabelas CSV em JSON e vice-versa — aspas, vírgulas dentro de aspas e ficheiros `;` suportados; JSON volta para CSV com colunas unidas automaticamente.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
