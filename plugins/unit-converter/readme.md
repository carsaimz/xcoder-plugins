# Unit Converter

Convert length, mass, data size, speed and temperature units.

**Unit Converter** covers mm→mi, mg→lb, B→TB, m/s→knot and °C⇄°F⇄K, with a clean insert-result dialog. Numbers are formatted sensibly (rounding at 6 decimals, exponentials for extremes).

## Português
**Conversor de unidades**: comprimento, massa, tamanho de dados, velocidade e temperatura — do mm ao mi, do B ao TB, °C⇄°F⇄K, com inserção do resultado no editor.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
