# Color Contrast

WCAG 2.1 contrast checker with accessible suggestions.

**Color Contrast** computes the contrast ratio between a foreground and a background color (hex or rgb) and reports AA/AAA pass/fail for normal text, large text and UI components — plus instant suggestions (black/white text on your background, your color on black/white).

## Português
**Contraste de cores**: rácio WCAG entre texto e fundo (hex/rgb) com veredicto AA/AAA para texto normal, grande e componentes UI, e sugestões imediatas de combinações acessíveis.

Part of the Xcoder plugin marketplace — installed via **Extensions**.
